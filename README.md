## Transit Scarcity Tracking System (TSTS)

The complete React + Vite demonstration app lives in [`tsts/`](./tsts). It includes the planning dashboard, interactive Leaflet map, citizen report workflow, zones registry, and federal program references.

```sh
cd tsts
npm install
npm run dev
```

Requires Node.js 22.12+ or 24+. See [`tsts/README.md`](./tsts/README.md) for setup, tests, demo-data limitations, and architecture.
